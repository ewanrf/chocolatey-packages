Official deployment documentation:
https://support.claude.com/en/articles/12622703-deploy-claude-desktop-for-windows

The package downloads Anthropic's current release from:
x64: https://claude.ai/api/desktop/win32/x64/msix/latest/redirect
ARM64: https://claude.ai/api/desktop/win32/arm64/msix/latest/redirect

There is intentionally no fixed checksum because these URLs track new releases.
Before installation, chocolateyinstall.ps1 requires a Valid Authenticode status
and the exact Anthropic publisher identity. It also checks the signed MSIX
manifest's app name (Claude), publisher, architecture and minimum OS version.
The downloaded manifest version is compared with the installed version to
avoid reinstalling or downgrading an equal or newer app.

On 3 September 2026, both payloads had Valid signatures from Anthropic, PBC,
and AppxManifest.xml reported version 1.44121.4.0. Future releases may differ.
No vendor installer is embedded in the Chocolatey package.
